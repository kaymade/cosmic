# Contributing to cosmic

Thank you for your interest in helping to improve **cosmic**. Bug reports, special requests, suggestions, and pull requests are all welcome here!

Please check out the guidance below to figure out how to best navigate the project and getting in contact with me.

## Reporting a Bug

If you find a bug, please open a GitHub issue and include:

- Your Obsidian version
- Your operating system
- Whether you are using dark or light mode
- A screenshot if possible
- Steps to reproduce the issue
- What you expected to happen and what happened instead
- Steps to reproduce the problem

Please **ALWAYS** check the existing open issues first. If someone has already reported the problem, add any new details you may have found to that existing issue, please do not create an additional one.

## Suggesting Changes

Suggestions are not just welcome, but they are highly encouraged. If you have a suggestion that you would like to make, please do the following:

1. Open an issue
2. Describe what you'd like to see changed about _cosmic_ and why

_For large changes, start the discussion before writing code, so we can agree on the scope of the changes please._

## Opening a Pull Request

If you are interested in tackling an open issue and creating a pull request, check out the guidance below!

#### Before opening a pull request, please make sure:

- The theme still works in both dark and light mode
- `manifest.json` remains valid JSON
- Version numbers follow `x.y.z`
- Changes preserve the overall Alice Velvet aesthetic

#### When opening a pull request, please:

1. Fork the repository and create a branch from `main`
2. Keep your changes focused and follow the conventions in the surrounding files
3. Run any relevant checks and test the behavior you changed
4. Open a pull request against `main`. Describe what changed, how you tested it, and anything you couldn't verify. Link the related issue if there is one.

For visual changes, please include before and after screenshots, when practical.

## Contact

For questions, concerns, or feedback related to contributing or **cosmic** at large, please contact `sagacloud` on Discord.
