# Contributing to Cosmic

Bug reports, feature requests, accessibility feedback, and pull requests are welcome.

## Before reporting a visual issue

Temporarily disable other CSS snippets and appearance-related plugins. If the issue disappears, include the conflicting snippet or plugin in the report so the interaction can be reproduced.

## Include this information

- Obsidian version
- Operating system and version
- Desktop, tablet, or phone
- Light or dark mode
- Cosmic color scheme
- Relevant Style Settings choices
- A screenshot of the affected area
- Minimal Markdown or steps that reproduce the issue
- Any active CSS snippets or appearance-related plugins

## Pull requests

Keep changes focused and explain which Obsidian surface or selector they affect. Check both light and dark mode, and test at least the Original palette plus the palette most affected by the change.

Please preserve Cosmic's continuous code-block design: a code block should read as one container, not a stack of individually rounded lines.
