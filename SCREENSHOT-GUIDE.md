# Cosmic screenshot guide

The Community Themes listing can show multiple desktop and mobile screenshots. A stronger gallery should make Cosmic's range obvious before someone installs it.

## Capture setup

- Use a clean demonstration vault with no unrelated CSS snippets
- Use the current public Obsidian release
- Keep the same note content and window size across palette comparisons
- Capture native-resolution images without added device frames or marketing text
- Avoid personal vault names, file names, and account details

## Recommended desktop set

1. **Hero:** Original dark mode with the note editor, file explorer, and graph visible
2. **Light mode:** Original light mode with headings, callouts, a table, and code
3. **Palette range:** A clearly different palette such as Aurora or Blue Blob
4. **Productivity:** Bases cards/groups, properties, search, and backlinks
5. **Customization:** Style Settings open beside a representative note

## Recommended mobile set

1. Original dark mode in a note
2. Original light mode in a note
3. Mobile navigation or sidebar
4. A customized palette
5. A content-heavy note showing tables, callouts, and code

## Final checks

- Confirm every screenshot reflects the release files
- Check text at thumbnail size
- Keep the most visually distinctive screenshot first
- Update `cosmic-screenshot.png` in the repository to match the first listing image
